# Учебный проект OOPDomashka Ecommerce

## Описание проекта

Учебный проект "Ecommerce" для решения задач с использованием ООП-подхода.

## Инструкция по установке и запуску

### Установка зависимостей

1. Убедитесь, что у вас установлены Python 3.x и Poetry.

2. Активируйте виртуальное окружение 

   poetry install

3. Клонируйте репозиторий

   https://github.com/kev7570-debug/Ecommerce
    

### Запуск проекта

1. Переместитесь в корень проекта и запустите демонстрацию всех модулей:

    python src/main.py


## Модули

### 1. `product.py`

Модуль описывает класс Product, представляющий товары.

1.**В модуле Product созданы 2 класса-наследника**: 
    - «Смартфон» (Smartphone) 
    - и «Трава газонная» (LawnGrass). 

2.**Добавлен абстрактный класс `BaseProduct`**:
   - Создан базовый абстрактный класс `BaseProduct`, который служит родительским для всех классов продуктов.
   - Классы `Smartphone` и `LawnGrass` теперь наследуются только от класса `Product`, который, в свою очередь, наследуется от `BaseProduct`.

3.**Реализован класс-миксин `CreationLoggerMixin`**:
   - Добавлен миксин, который при создании объекта печатает информацию о том, от какого класса и с какими параметрами был создан объект.
   - Миксин добавлен в цепочку наследования класса `Product`.

### 2. `category.py`

Модуль описывает класс Category, позволяющий создавать категории товаров.


### 3. `main.py`

Главный модуль для демонстрации работы всех подсистем. Служит отправной точкой для запуска теста отдельных частей системы.
